Sicherungskonzept

Wie Selbstlernphasen und gemeinsame Sicherung zusammengehen

Der Rhythmus

Jede Etappe beginnt mit einer Ansage der Lehrkraft nach dem Muster der blauen Etappenbalken: „Die nächsten 30 Minuten: Wissenskasten lesen, Aufgaben 2.1 und 2.2. Wer fertig ist, macht 2.6. Dann Stopp.“ Ein sichtbarer Timer am Board hilft. Der Stopp-Kasten sagt den Schülerinnen und Schülern, was sie für die Besprechung vorbereiten sollen. Die Zeiten sind auf die Pflichtaufgaben bemessen. Schnelle Schülerinnen und Schüler arbeiten an den Erweiterungen, langsame bearbeiten Basisaufgaben und sehen sich die Lösungen erklärend an.

Fünf Formen der Sicherung

Code-Stände synchronisieren

Nach den Sicherungen 4.B, 5.B und 5.D gibt die Lehrkraft einen gemeinsamen Stand von bank.py über den Austauschordner aus (siehe Code-Stände). So arbeiten auch Schülerinnen und Schüler, die gefehlt haben oder nicht fertig wurden, mit einem lauffähigen Programm weiter. Ihre eigene Datei behalten sie zum Vergleich.

class Konto:
    def __init__(self, kontonummer, pin):
        self.kontonummer = kontonummer
        self.pin = pin
        self.kontostand = 0.0
        self.dispo = 500.0
        self.buchungen = []

    def get_kontonummer(self):
        return self.kontonummer

    def get_kontostand(self):
        return self.kontostand

    def pin_pruefen(self, eingabe):
        return eingabe == self.pin

    def einzahlen(self, betrag):
        if betrag > 0:
            self.kontostand = self.kontostand + betrag
            self.buchungen.append(betrag)
        else:
            print("Einzahlung abgelehnt: Der Betrag muss positiv sein.")

    def abheben(self, betrag):
        if betrag <= 0:
            print("Abhebung abgelehnt: Der Betrag muss positiv sein.")
        elif self.kontostand - betrag >= -self.dispo:
            self.kontostand = self.kontostand - betrag
            self.buchungen.append(-betrag)
        else:
            print("Abhebung abgelehnt: Der Dispo reicht nicht aus.")

    def ueberweisen(self, betrag, zielkonto):
        if betrag <= 0:
            print("Überweisung abgelehnt: Der Betrag muss positiv sein.")
        elif self.kontostand - betrag >= -self.dispo:
            self.kontostand = self.kontostand - betrag
            self.buchungen.append(-betrag)
            zielkonto.einzahlen(betrag)
        else:
            print("Überweisung abgelehnt: Der Dispo reicht nicht aus.")

    def auszug_drucken(self):
        print("Kontoauszug für Konto", self.kontonummer)
        for buchung in self.buchungen:
            print(buchung, "€")
        print("Kontostand:", self.kontostand, "€")
