Sequenz - die Turtle in Bewegung

2 Unterrichtsstunden  ·  Erste Programme: Befehle werden Schritt für Schritt von oben nach unten abgearbeitet.

Ziele dieses Kapitels

  • ein Python-Programm starten und den Programmablauf als Sequenz beschreiben
  • die Grundbefehle der Turtle gezielt einsetzen
  • eine vorgegebene Zeichnung in eine Befehlsfolge zerlegen

Das brauchst du

Jedes Turtle-Programm beginnt damit, das Modul zu laden, und endet damit, das Fenster offen zu halten:

import turtle

turtle.forward(100)

turtle.done()

Die Turtle ist ein Stift mit Blickrichtung. Sie startet in der Mitte (0, 0) und schaut nach rechts (Osten).

BefehlWirkung
forward(100) / fd(100)100 Schritte vorwärts
backward(50) / bk(50)50 Schritte rückwärts
right(90) / rt(90)dreht sich um 90° nach rechts
left(90) / lt(90)dreht sich um 90° nach links
penup() / pendown()Stift heben / senken
goto(x, y)fährt zum Punkt (x, y)
setheading(0)dreht auf eine absolute Richtung (0 = rechts, 90 = oben)
pencolor("red")Stiftfarbe
pensize(5)Strichstärke
speed(0)Zeichengeschwindigkeit (0 = am schnellsten)
hideturtle()Turtle-Symbol ausblenden

Sequenz heißt: Die Anweisungen werden in genau der Reihenfolge ausgeführt, in der sie im Quelltext stehen. Vertauscht man zwei Zeilen, entsteht in aller Regel ein anderes Bild.

1.1
Erste Schritte
Basis

Lege eine Datei quadrat.py an und zeichne ein Quadrat mit der Seitenlänge 120 — ohne Schleife, also mit acht einzelnen Befehlen.

Ändere anschließend die Farbe auf Blau und die Strichstärke auf 4.

Tipp 1Ein Quadrat hat vier gleich lange Seiten und vier rechte Winkel. Für jede Ecke brauchst du eine Drehung um 90°.
Tipp 2Die Reihenfolge ist immer: vorwärts, drehen, vorwärts, drehen, ... Beginne mit turtle.pencolor("blue") und turtle.pensize(4) ganz oben.
Lösung und Erläuterung
import turtle

turtle.pencolor("blue")
turtle.pensize(4)

turtle.forward(120)
turtle.right(90)
turtle.forward(120)
turtle.right(90)
turtle.forward(120)
turtle.right(90)
turtle.forward(120)
turtle.right(90)

turtle.done()

Die letzte Drehung ist optional für das Bild, aber sinnvoll: Danach steht die Turtle wieder genau so da wie am Anfang. Solche „aufgeräumten“ Bausteine lassen sich später problemlos aneinanderhängen.

1.2
Treppe
Basis

Zeichne eine Treppe mit drei Stufen. Jede Stufe ist 50 Schritte hoch und 50 Schritte breit.

Zusatz: Wie viele Befehlszeilen brauchst du? Notiere die Zahl und vergleiche sie später mit deiner Lösung aus Kapitel 3.

Tipp 1Eine Stufe besteht aus: nach oben, dann nach rechts. Zwischen den Teilstrecken musst du drehen.
Tipp 2Die Turtle schaut zu Beginn nach rechts. Drehe also zuerst mit left(90) nach oben, gehe 50, drehe mit right(90) zurück nach rechts, gehe 50 — und das dreimal.
Lösung und Erläuterung
import turtle

turtle.pensize(3)

# 1. Stufe
turtle.left(90)
turtle.forward(50)
turtle.right(90)
turtle.forward(50)

# 2. Stufe
turtle.left(90)
turtle.forward(50)
turtle.right(90)
turtle.forward(50)

# 3. Stufe
turtle.left(90)
turtle.forward(50)
turtle.right(90)
turtle.forward(50)

turtle.done()

Zwölf Befehle für drei Stufen. Auffällig: Der Block von vier Zeilen wiederholt sich exakt. Genau solche Wiederholungen ersetzt man später durch eine for-Schleife (Kapitel 3) oder eine Funktion (Kapitel 5).

1.3
Haus vom Nikolaus
Standard

Zeichne das Haus vom Nikolaus in einem Zug — die Turtle darf den Stift nicht heben.

Das Haus besteht aus einem Quadrat (Seitenlänge 100), den beiden Diagonalen und einem gleichschenkligen Dach.

Prüffrage: Warum muss die Turtle in einer unteren Ecke starten? Probiere es zum Vergleich einmal von „oben links“ aus.

Tipp 1Die Diagonale eines Quadrats mit Seitenlänge 100 ist ungefähr 141 Schritte lang (100 · √2).
Tipp 2Statt jeden Winkel einzeln auszurechnen, hilft setheading(): Damit gibst du absolute Richtungen an — 0 = rechts, 90 = oben, 45 = schräg rechts oben, 135 = schräg links oben.
Tipp 3Die Dachschräge trifft die Firstspitze unter 45°. Ihre Länge ist etwa 71 Schritte (die Hälfte der Diagonale).
Lösung und Erläuterung
import turtle

turtle.pensize(3)
turtle.pencolor("darkred")

# Startpunkt: unten LINKS  (Ecken: A unten links, B unten rechts,
# C oben rechts, D oben links, E Dachspitze)
turtle.penup()
turtle.goto(-50, -100)
turtle.pendown()

turtle.setheading(0)
turtle.forward(100)             # A -> B   Boden
turtle.setheading(90)
turtle.forward(100)             # B -> C   rechte Wand
turtle.setheading(180)
turtle.forward(100)             # C -> D   Decke
turtle.setheading(270)
turtle.forward(100)             # D -> A   linke Wand
turtle.setheading(45)
turtle.forward(141.4)           # A -> C   1. Diagonale (100 * Wurzel 2)
turtle.setheading(135)
turtle.forward(70.7)            # C -> E   rechte Dachschraege
turtle.setheading(225)
turtle.forward(70.7)            # E -> D   linke Dachschraege
turtle.setheading(-45)
turtle.forward(141.4)           # D -> B   2. Diagonale

turtle.done()

Mit setheading() denkst du in absoluten Richtungen statt in Drehwinkeln — das ist bei schrägen Linien deutlich weniger fehleranfällig.

Zur Prüffrage: Das Haus vom Nikolaus ist ein Eulerweg. Ein solcher Weg existiert nur, wenn genau zwei Ecken eine ungerade Anzahl von Kanten haben — das sind hier die beiden unteren Ecken (an ihnen treffen jeweils drei Linien zusammen). Man muss also zwingend in einer unteren Ecke starten und endet dann automatisch in der anderen. Von „oben links“ aus bleibt immer mindestens eine Linie übrig.

1.4
Dein Initial
Standard

Zeichne den Anfangsbuchstaben deines Vornamens als Turtle-Grafik, ungefähr 150 Schritte hoch.

Runde Buchstaben darfst du eckig annähern oder mit turtle.circle(radius, winkel) zeichnen.

Kommentiere im Quelltext, welcher Befehlsblock welchen Teil des Buchstabens malt.

Tipp 1Zeichne den Buchstaben zuerst auf kariertem Papier und trage die Schrittzahlen ein. Erst danach tippen.
Tipp 2turtle.circle(50, 180) zeichnet einen Halbkreis mit Radius 50. Der Kreis wird immer links von der Turtle gezeichnet.
Tipp 3Für abgesetzte Teilstriche (z. B. beim „T“ oder „K“): penup() → goto(...) → pendown().
Lösung und Erläuterung
import turtle

turtle.pensize(6)
turtle.pencolor("teal")
turtle.speed(3)

# Beispiel: Buchstabe "M"
turtle.penup()
turtle.goto(-60, -75)
turtle.pendown()

turtle.setheading(90)
turtle.forward(150)             # linker Senkrechtstrich
turtle.setheading(-60)
turtle.forward(90)              # Schraege nach unten rechts
turtle.setheading(60)
turtle.forward(90)              # Schraege nach oben rechts
turtle.setheading(-90)
turtle.forward(150)             # rechter Senkrechtstrich

turtle.hideturtle()
turtle.done()

Das Muster „Stift heben – positionieren – Stift senken“ brauchst du bei fast jeder mehrteiligen Grafik. Merke dir die drei Zeilen als Baustein; in Kapitel 5 machst du daraus eine eigene Funktion gehe_zu(x, y).

1.5
Fehlersuche im Fremdcode
Erweiterung

Das folgende Programm soll ein gleichseitiges Dreieck mit der Seitenlänge 100 zeichnen. Es tut es aber nicht.

import turtle

turtle.forward(100)
turtle.right(60)
turtle.forward(100)
turtle.right(60)
turtle.forward(100)

turtle.done()

a) Beschreibe, welche Figur tatsächlich entsteht.
b) Finde den Fehler und begründe ihn geometrisch.
c) Verallgemeinere: Welchen Drehwinkel braucht ein regelmäßiges n-Eck?

Tipp 1Zeichne den Weg mit Bleistift nach: Wo steht die Turtle nach dem zweiten forward, und in welche Richtung schaut sie?
Tipp 2Unterscheide sauber zwischen dem Innenwinkel der Figur (beim Dreieck 60°) und dem Drehwinkel der Turtle (dem Außenwinkel).
Tipp 3Die Turtle läuft die Figur einmal komplett ab und schaut am Ende wieder in die Startrichtung. Insgesamt hat sie sich also um 360° gedreht.
Lösung und Erläuterung
import turtle

# a) Es entsteht ein offener Streckenzug mit zwei stumpfen Knicken -
#    kein geschlossenes Dreieck.
# b) 60 Grad ist der INNENwinkel. Die Turtle dreht sich aber um den
#    AUSSENwinkel: 180 - 60 = 120 Grad.
# c) Regelmaessiges n-Eck: Drehwinkel = 360 / n

turtle.pensize(3)

turtle.forward(100)
turtle.right(120)
turtle.forward(100)
turtle.right(120)
turtle.forward(100)
turtle.right(120)

turtle.done()

Die Winkelsumme der Außenwinkel beträgt bei jedem geschlossenen Polygon 360°. Bei n gleichen Ecken entfällt auf jede Ecke der Drehwinkel 360/n. Für das Dreieck: 360/3 = 120°, für das Quadrat 360/4 = 90°, für das Sechseck 360/6 = 60°.

Diese Formel ist der Schlüssel für Aufgabe 3.2 — merke sie dir.

Variablen, Datentypen und Typkonvertierung

2 Unterrichtsstunden  ·  Werte benennen, Datentypen unterscheiden und ineinander umwandeln.

Ziele dieses Kapitels

  • Variablen sinnvoll benennen und einsetzen
  • die Datentypen int, float, str und bool unterscheiden
  • Daten mit int(), float() und str() in einen anderen Datentyp konvertieren
  • Benutzereingaben entgegennehmen und weiterverarbeiten

Das brauchst du

Eine Variable ist ein benannter Speicherplatz. Die Zuweisung erfolgt mit =, gelesen als „bekommt den Wert“:

seite = 120
farbe = "blue"
faktor = 1.5
DatentypBedeutungBeispiel
intganze Zahl42, -7
floatKommazahl (Punkt!)3.14, -0.5
strZeichenkette"rot", "120"
boolWahrheitswertTrue, False

Typkonvertierung (Casting) wandelt einen Wert in einen anderen Typ um:

int("120")     # -> 120        (str  -> int)
int(3.99)      # -> 3          (float -> int, schneidet ab!)
float("2.5")   # -> 2.5        (str  -> float)
str(120)       # -> "120"      (int  -> str)
round(3.99)    # -> 4          (rundet kaufmaennisch)
type(seite)    # zeigt den Datentyp an

Eingabe — in Turtle-Programmen bequem über kleine Dialogfenster:

fenster = turtle.Screen()
laenge  = fenster.numinput("Titel", "Seitenlaenge?", 100)   # liefert float
name    = fenster.textinput("Titel", "Dein Name?")          # liefert str

Typischer Stolperstein: numinput() liefert immer einen float. Wenn du damit zählen willst (z. B. Ecken eines Vielecks), musst du mit int(...) konvertieren. Und: "5" + 3 ist ein Fehler, int("5") + 3 ergibt 8, "5" + str(3) ergibt "53".

2.1
Quadrat mit Variable
Basis

Schreibe dein Quadrat aus Aufgabe 1.1 so um, dass die Seitenlänge in einer Variablen seite steht.

Teste dein Programm mit den Werten 50, 120 und 200 — du darfst dafür nur eine einzige Zeile ändern.

Tipp 1Lege die Variable ganz oben an: seite = 120.
Tipp 2Schreibe danach überall turtle.forward(seite) statt turtle.forward(120).
Lösung und Erläuterung
import turtle

seite = 120          # nur diese Zeile aendern!

turtle.pensize(3)
turtle.forward(seite)
turtle.right(90)
turtle.forward(seite)
turtle.right(90)
turtle.forward(seite)
turtle.right(90)
turtle.forward(seite)
turtle.right(90)

turtle.done()

Das ist das Prinzip der einen Quelle: Ein Wert, der an mehreren Stellen gebraucht wird, steht nur einmal im Programm. Änderungen werden dadurch schnell und fehlerfrei.

2.2
Datentypen erkennen
Basis

Notiere zuerst auf Papier, welchen Datentyp jeder Ausdruck hat. Prüfe dann mit print(type(...)).

  1. 120
  2. 120.0
  3. "120"
  4. 120 / 4
  5. 120 // 4
  6. 120 > 4
  7. "12" + "0"
  8. int("120") / 2
Tipp 1Die normale Division / liefert in Python immer einen float — auch wenn das Ergebnis glatt aufgeht.
Tipp 2// ist die Ganzzahldivision, % der Rest. Vergleiche liefern immer bool.
Lösung und Erläuterung
print(type(120))            # <class 'int'>
print(type(120.0))          # <class 'float'>
print(type("120"))          # <class 'str'>
print(type(120 / 4))        # <class 'float'>   -> 30.0
print(type(120 // 4))       # <class 'int'>     -> 30
print(type(120 > 4))        # <class 'bool'>    -> True
print(type("12" + "0"))     # <class 'str'>     -> "120"
print(type(int("120") / 2)) # <class 'float'>   -> 60.0

Merke: / erzeugt immer float, // bleibt bei int. Das + bei zwei Strings ist keine Addition, sondern eine Verkettung (Konkatenation).

2.3
Vieleck nach Wunsch
Standard

Frage den Benutzer über ein Dialogfenster nach der Eckenzahl und der Seitenlänge und zeichne das passende regelmäßige Vieleck.

Achte darauf, dass die Eckenzahl eine ganze Zahl sein muss — konvertiere sie entsprechend.

Schreibe abschließend mit turtle.write() den Text „n-Eck, Seite s“ neben die Figur.

Tipp 1fenster = turtle.Screen(), dann fenster.numinput("Vieleck", "Wie viele Ecken?", 6). Der dritte Parameter ist der Vorgabewert.
Tipp 2numinput liefert einen float wie 6.0. Mit ecken = int(fenster.numinput(...)) erhältst du eine ganze Zahl.
Tipp 3turtle.write() erwartet einen String. Zahlen musst du mit str() umwandeln und mit + anhängen.
Lösung und Erläuterung
import turtle

fenster = turtle.Screen()

ecken = int(fenster.numinput("Vieleck", "Wie viele Ecken?", 6))
seite = fenster.numinput("Vieleck", "Wie lang ist eine Seite?", 80)

winkel = 360 / ecken

turtle.pensize(3)
turtle.pencolor("darkgreen")

for i in range(ecken):
    turtle.forward(seite)
    turtle.right(winkel)

# Beschriftung: Zahlen muessen zu Text konvertiert werden
text = str(ecken) + "-Eck, Seite " + str(int(seite))
turtle.penup()
turtle.goto(-120, -150)
turtle.write(text, font=("Arial", 14, "normal"))

turtle.hideturtle()
turtle.done()

Zwei Konvertierungen in einem Programm: int(...) beim Einlesen der Eckenzahl (weil range() nur ganze Zahlen akzeptiert) und str(...) bei der Ausgabe (weil write() Text erwartet).

Der Drehwinkel 360 / ecken darf ruhig ein float bleiben — right() kommt damit klar.

2.4
Vier Fehler
Standard

Im folgenden Programm stecken vier Fehler, die alle mit Datentypen zu tun haben. Finde sie, benenne den jeweiligen Fehlertyp und korrigiere sie.

import turtle

fenster = turtle.Screen()
anzahl = fenster.numinput("Kreise", "Wie viele?", 5)

for i in range(anzahl):
    turtle.circle(20)
    turtle.right(360 / anzahl)

turtle.write("Fertig: " + anzahl + " Kreise")
turtle.write("Radius: " + 20)

turtle.done()
Tipp 1Was liefert numinput genau — und was verlangt range()?
Tipp 2Was passiert, wenn man einen String mit einer Zahl per + verbinden will?
Tipp 3Achte auch darauf, ob anzahl überhaupt jemals 0 sein könnte — was würde dann bei 360 / anzahl passieren?
Lösung und Erläuterung
import turtle

fenster = turtle.Screen()

# FEHLER 1: numinput liefert float, range() braucht int -> int(...)
anzahl = int(fenster.numinput("Kreise", "Wie viele?", 5))

# FEHLER 4 (Absicherung): Division durch 0 vermeiden
if anzahl < 1:
    anzahl = 1

for i in range(anzahl):
    turtle.circle(20)
    turtle.right(360 / anzahl)

# FEHLER 2: str + int geht nicht -> str(anzahl)
turtle.write("Fertig: " + str(anzahl) + " Kreise")

# FEHLER 3: gleicher Fehler mit einer Literal-Zahl -> str(20)
turtle.write("Radius: " + str(20))

turtle.done()
  • Fehler 1 — TypeError: 'float' object cannot be interpreted as an integer: range() verlangt int.
  • Fehler 2 und 3 — TypeError: can only concatenate str (not "int") to str: Text und Zahl lassen sich nicht mit + verbinden.
  • Fehler 4 — ZeroDivisionError, sobald der Benutzer 0 eingibt. Ein Laufzeitfehler, den man durch eine Plausibilitätsprüfung abfängt.

Alternativ zur Verkettung geht auch ein f-String: turtle.write(f"Fertig: {anzahl} Kreise") — die Konvertierung passiert dann automatisch.

2.5
Skalierbares Logo
Erweiterung

Entwirf ein kleines Logo aus mindestens vier Teilstrecken (z. B. ein stilisiertes Haus, ein Pfeil, ein Blitz).

Führe eine Variable skala ein, mit der sich die gesamte Grafik vergrößern oder verkleinern lässt. Bei skala = 1 soll das Logo die Grundgröße haben, bei skala = 2 die doppelte.

Frage skala per numinput ab und passe zusätzlich die Strichstärke proportional an — sie muss aber eine ganze Zahl und mindestens 1 sein.

Tipp 1Alle Längen mit skala multiplizieren: turtle.forward(50 * skala). Winkel bleiben unverändert!
Tipp 2Für die Strichstärke: dicke = int(3 * skala). Mit if dicke < 1: dicke = 1 verhinderst du die Strichstärke 0.
Tipp 3Praktischer ist es, eine Hilfsvariable e = 50 * skala („Einheit“) zu definieren und im Programm nur noch Vielfache von e zu verwenden.
Lösung und Erläuterung
import turtle

fenster = turtle.Screen()
skala = fenster.numinput("Logo", "Skalierungsfaktor (0.5 - 3)?", 1)

e = 50 * skala                  # eine "Einheit" der Grafik

dicke = int(3 * skala)          # float -> int
if dicke < 1:                   # Strichstaerke 0 waere unsichtbar
    dicke = 1
turtle.pensize(dicke)
turtle.pencolor("navy")

# stilisiertes Haus
turtle.penup()
turtle.goto(-e, -e)
turtle.pendown()

turtle.setheading(0)
turtle.forward(2 * e)           # Boden
turtle.left(90)
turtle.forward(2 * e)           # rechte Wand
turtle.left(90)
turtle.forward(2 * e)           # Decke
turtle.left(90)
turtle.forward(2 * e)           # linke Wand

turtle.setheading(0)            # zur Dachspitze
turtle.penup()
turtle.goto(-e, e)
turtle.pendown()
turtle.setheading(45)
turtle.forward(1.41 * e)
turtle.setheading(-45)
turtle.forward(1.41 * e)

turtle.hideturtle()
turtle.done()

Zwei Ideen stecken darin:

  • Relative Maße. Statt absoluter Zahlen rechnest du in Vielfachen einer Einheit e. Das Bild bleibt bei jeder Skalierung proportional.
  • Konvertierung mit Plausibilitätsprüfung. int() schneidet ab — aus 3 · 0.2 = 0.6 würde 0. Deshalb die Absicherung auf das Minimum 1.

Winkel werden beim Skalieren nicht verändert — eine zentrale geometrische Einsicht: Ähnlichkeitsabbildungen sind winkeltreu.

Wiederholung - Schleifen

2 Unterrichtsstunden  ·  Zählschleife und bedingte Schleife: Wiederholungen kompakt und lesbar formulieren.

Ziele dieses Kapitels

  • die Kontrollstruktur Wiederholung erkennen und implementieren
  • die Zählschleife (for) und die bedingte Schleife (while) unterscheiden
  • die Schleifenvariable als Wert im Rumpf nutzen
  • verschachtelte Schleifen lesen und schreiben

Das brauchst du

Zählschleife — die Anzahl der Durchläufe steht vorher fest:

for i in range(4):
    turtle.forward(100)
    turtle.right(90)

Alles, was eingerückt ist (vier Leerzeichen), gehört zum Schleifenrumpf. Die Variable i zählt dabei mit:

Aufrufi nimmt nacheinander die Werte an
range(5)0, 1, 2, 3, 4
range(1, 6)1, 2, 3, 4, 5
range(0, 100, 20)0, 20, 40, 60, 80
range(10, 0, -2)10, 8, 6, 4, 2

Bedingte Schleife — die Anzahl der Durchläufe ist vorher unbekannt:

laenge = 5
while laenge < 200:
    turtle.forward(laenge)
    turtle.right(90)
    laenge = laenge + 10

Wichtig: Bei while musst du selbst dafür sorgen, dass sich die Bedingung irgendwann ändert — sonst läuft das Programm endlos. Bei for passiert das automatisch.

Verschachtelung: Eine Schleife im Rumpf einer anderen Schleife. Die innere Schleife läuft bei jedem Durchlauf der äußeren komplett durch. Bei 8 äußeren und 4 inneren Durchläufen wird der innere Rumpf 8 · 4 = 32-mal ausgeführt.

3.1
Quadrat und Treppe kompakt
Basis

a) Schreibe das Quadrat aus Aufgabe 1.1 mit einer for-Schleife. Wie viele Zeilen sparst du?

b) Mache dasselbe mit der Treppe aus 1.2 — und erweitere sie danach auf zehn Stufen, ohne neue Zeilen hinzuzufügen.

Tipp 1Suche den Block, der sich wortwörtlich wiederholt. Genau dieser Block kommt in den Schleifenrumpf.
Tipp 2Die Zahl in range(...) gibt an, wie oft der Block ausgeführt wird.
Lösung und Erläuterung
import turtle

turtle.pensize(3)

# a) Quadrat: 8 Zeilen werden zu 3
for i in range(4):
    turtle.forward(120)
    turtle.right(90)

# b) Treppe mit 10 Stufen: nur die Zahl in range() aendert sich
turtle.penup()
turtle.goto(-250, -150)
turtle.pendown()
turtle.setheading(0)

for i in range(10):
    turtle.left(90)
    turtle.forward(30)
    turtle.right(90)
    turtle.forward(30)

turtle.done()

  • Abbruch hängt von einer Bedingung ab → while

Tipp 1Zwei verschachtelte Schleifen: for zeile in range(8) und darin for spalte in range(8).
Tipp 2Füllen: turtle.fillcolor(farbe), dann begin_fill(), das Quadrat zeichnen, end_fill().
Tipp 3Die Farbe hängt von beiden Zählern ab. Betrachte (zeile + spalte) % 2 — in benachbarten Feldern wechselt diese Zahl.

turtle.tracer(0)
turtle.pensize(1)

    for spalte in range(8):

        turtle.penup()
        turtle.goto(start_x + spalte * feld, start_y + zeile * feld)
        turtle.setheading(0)
        turtle.pendown()

        if (zeile + spalte) % 2 == 0:
            turtle.fillcolor("white")
        else:

            turtle.left(90)

turtle.done()

Zur Denkfrage: spalte % 2 hängt nur von der waagerechten Position ab. In jeder Zeile ergibt sich dasselbe Muster — also senkrechte Streifen.

4.4
Randerkennung
Standard

Die Turtle soll 200-mal einen zufälligen Schritt machen. Sobald sie den sichtbaren Bereich verlässt (|x| > 250 oder |y| > 250), soll sie in die Mitte zurückgesetzt werden.

Formuliere die Bedingung mit or. Färbe die Spur rot ein, solange die Turtle sich im inneren Bereich (|x| < 100 und |y| < 100) befindet, sonst blau.

Tipp 1Zufallszahlen: import random, dann random.randint(-90, 90) für den Drehwinkel.
Tipp 2Position abfragen: turtle.xcor() und turtle.ycor(). Den Betrag liefert abs(...).
Tipp 3Zurücksetzen ohne Strich: penup() → goto(0, 0) → pendown().
Lösung und Erläuterung
import turtle
import random

turtle.pensize(2)

    # Farbe abhaengig vom inneren Bereich -> and
    if abs(turtle.xcor()) < 100 and abs(turtle.ycor()) < 100:
        turtle.pencolor("red")
    else:
        turtle.pencolor("blue")

    turtle.right(random.randint(-90, 90))
    turtle.forward(20)

    # Rand verlassen? -> or
    if abs(turtle.xcor()) > 250 or abs(turtle.ycor()) > 250:
        turtle.penup()
        turtle.goto(0, 0)
        turtle.pendown()

turtle.hideturtle()
turtle.done()

Beide logischen Operatoren in einem Programm, und beide an der inhaltlich passenden Stelle:

  • and für „im inneren Quadrat“ — beide Koordinaten müssen klein sein.
  • or für „Rand verlassen“ — eine überschrittene Koordinate genügt.

Nach dem Gesetz von De Morgan gilt: „nicht (|x| < 250 and |y| < 250)“ ist dasselbe wie „|x| ≥ 250 or |y| ≥ 250“. Beim Umformen von Bedingungen kippt and zu or — ein häufiger Fehler.

4.6
Turtle im Kasten
Erweiterung

Simuliere eine Kugel, die in einem Kasten (600 × 400) hin und her prallt.

Tipp 2Aktuelle Richtung: turtle.heading(). Neue Richtung setzen: turtle.setheading(...).
Tipp 3Die beiden Reflexionsfälle brauchen getrennte if-Blöcke (nicht elif) — in einer Ecke treten beide gleichzeitig auf.
Tipp 4Damit die Turtle nicht im Rand „hängen bleibt“, prüfe knapp innerhalb der Grenze, z. B. abs(x) > xmax - 10.
Lösung und Erläuterung

import random

ymax = 200

turtle.speed(0)
turtle.tracer(0)

turtle.goto(-xmax, -ymax)
turtle.pendown()
turtle.pensize(3)
turtle.pencolor("black")
for i in range(2):
    turtle.forward(2 * xmax)
    turtle.left(90)
    turtle.forward(2 * ymax)
    turtle.left(90)

# Kugel starten
turtle.penup()
turtle.goto(0, 0)
turtle.setheading(random.randint(20, 70))
turtle.pensize(1)
turtle.pencolor("crimson")

    turtle.forward(10)

    x = turtle.xcor()
    y = turtle.ycor()
    richtung = turtle.heading()

    # senkrechte Wand: an der Senkrechten spiegeln
    if abs(x) > xmax - 10:
        richtung = 180 - richtung
        turtle.setheading(richtung)

    # waagerechte Wand: an der Waagerechten spiegeln

        richtung = -turtle.heading()
        turtle.setheading(richtung)

turtle.update()
turtle.done()

Warum zwei getrennte if-Blöcke und kein elif? Weil in einer Ecke beide Bedingungen gleichzeitig wahr sind — dort muss zweimal gespiegelt werden. Mit elif würde die Kugel aus der Ecke herauslaufen.

Die Reflexionsformeln folgen direkt aus dem Einfallswinkel = Ausfallswinkel:

  • senkrechte Wand: die x-Komponente kehrt sich um → 180 - richtung
  • waagerechte Wand: die y-Komponente kehrt sich um → -richtung

Der Sicherheitsabstand - 10 entspricht der Schrittweite. Ohne ihn kann die Turtle in einem Schritt so weit über den Rand springen, dass sie auch nach der Spiegelung noch außerhalb ist — und dann in jedem Durchlauf erneut gespiegelt wird. Sie zittert dann am Rand fest.

5.6
Rekursiver Baum
Erweiterung

Eine Funktion darf sich selbst aufrufen — das nennt man Rekursion.

Schreibe baum(laenge, tiefe):

  • Ist tiefe gleich 0, wird nichts gezeichnet (Abbruchbedingung).
  • Sonst: Stamm zeichnen, um 25° nach links drehen und einen kleineren Baum zeichnen, um 50° nach rechts drehen und noch einen kleineren Baum zeichnen, zurückdrehen und zum Ausgangspunkt zurückfahren.

Zusatz: Lasse Strichstärke und Farbe von der Tiefe abhängen — dicke braune Äste unten, dünne grüne Zweige oben.

Tipp 1Die Abbruchbedingung steht immer ganz am Anfang der Funktion: if tiefe == 0: return.
Tipp 2Der rekursive Aufruf verkleinert beides: baum(laenge * 0.7, tiefe - 1). So wird die Abbruchbedingung garantiert erreicht.
Tipp 3Nach dem Zeichnen des Stamms mit turtle.forward(laenge) musst du am Ende exakt gleich weit zurück: turtle.backward(laenge).
Tipp 4Beginne mit tiefe = 3 und zeichne den Ablauf auf Papier nach, bevor du auf 10 hochgehst.
Lösung und Erläuterung
import turtle


def baum(laenge, tiefe):
    """Zeichnet rekursiv einen verzweigten Baum."""
    if tiefe == 0:                  # Abbruchbedingung
        return

    # Aussehen abhaengig von der Tiefe
    turtle.pensize(tiefe)
    if tiefe > 3:
        turtle.pencolor("saddlebrown")
    else:
        turtle.pencolor("forestgreen")

    turtle.forward(laenge)          # Stamm

    turtle.left(25)
    baum(laenge * 0.7, tiefe - 1)   # linker Teilbaum
    turtle.right(50)
    baum(laenge * 0.7, tiefe - 1)   # rechter Teilbaum
    turtle.left(25)

    turtle.backward(laenge)         # exakt zurueck zum Startpunkt


turtle.speed(0)
turtle.tracer(0)

turtle.penup()
turtle.goto(0, -250)
turtle.setheading(90)
turtle.pendown()

baum(110, 9)

turtle.hideturtle()
turtle.update()
turtle.done()

Rekursion steht nicht im Pflichtteil des Rahmenplans — sie ist hier als Ausblick für die Schnellen gedacht und zeigt, wie mächtig das Konzept „Unterprogramm“ ist.

Drei Bestandteile machen jede Rekursion aus:

  1. Abbruchbedingung — if tiefe == 0: return
  2. Verkleinerung — jeder Aufruf bekommt tiefe - 1
  3. Aufräumen — backward(laenge) und die Rückdrehungen stellen den Ausgangszustand wieder her

Bei tiefe = 9 wird die Funktion 2⁹ − 1 = 511-mal aufgerufen. Ohne tracer(0) würdest du minutenlang zuschauen.

Basis

del werte[0]
print(werte)                      # 7) [90, 25, 130, 60, 75]

werte[1] = 999
print(werte)                      # 8) [90, 999, 130, 60, 75]

Punkt 7 ist der wichtigste: Nach dem Löschen von Stelle 0 rutschen alle Elemente nach vorn. Die 25 stand vorher an Stelle 2, danach an Stelle 1. Genau deshalb überschreibt werte[1] = 999 in Schritt 8 die 25 und nicht die 90.

Diese Verschiebung ist die häufigste Fehlerquelle beim Löschen in Schleifen — wer beim Durchlaufen einer Liste Elemente entfernt, überspringt unbemerkt Elemente.

Standard

Lösung und Erläuterung
import turtle

BREITE = 40
LUECKE = 5
BASIS_Y = -150

hoehen = [80, 140, 45, 190, 95, 120, 60]


def gehe_zu(x, y):
    turtle.penup()
    turtle.goto(x, y)
    turtle.setheading(0)
    turtle.pendown()


def balken(x, hoehe, farbe):

def suche_stelle(liste, wert):
    """Liefert die Stelle des ersten Vorkommens - oder -1, falls nicht vorhanden."""
    for i in range(len(liste)):
        if liste[i] == wert:

    return -1                   # Schleife lief durch: nicht gefunden

  • Das return -1 steht außerhalb der Schleife. Innerhalb würde es schon nach dem ersten Vergleich zurückkehren — ein sehr häufiger Fehler.

Erweiterung

Tipp 3Die Schleife kann bei 1 starten: for i in range(1, len(liste)), weil Stelle 0 schon der Startwert ist.

Lösung und Erläuterung
import turtle

BREITE = 40
LUECKE = 5
BASIS_Y = -150

hoehen = [80, 140, 45, 190, 95, 120, 60]

Zwei Listen parallel
Erweiterung

Zwei Listen können zusammengehörige Daten speichern. Gegeben:

x_werte = [-250, -180, -110, -40, 30, 100, 170, 240]
y_werte = [ -80,   40,  120,  90, -30, -110, 60, 150]

a) Zeichne die Punkte als Polygonzug (Linienplot) mit einem Marker an jeder Stelle.
b) Färbe Punkte oberhalb der x-Achse grün, Punkte unterhalb rot.

Tipp 3Zeichne zuerst den kompletten Linienzug, dann in einer zweiten Schleife die Marker — sonst überzeichnen die Linien die Punkte.
Lösung und Erläuterung
import turtle

x_werte = [-250, -180, -110, -40, 30, 100, 170, 240]
y_werte = [-80, 40, 120, 90, -30, -110, 60, 150]

turtle.speed(0)
turtle.tracer(0)
turtle.hideturtle()

# d) Plausibilitaetspruefung
if len(x_werte) != len(y_werte):
    turtle.write("Fehler: Die Listen sind unterschiedlich lang!",
                 align="center", font=("Arial", 14, "bold"))
    turtle.done()
else:
    anzahl = len(x_werte)

    # Achsen
    turtle.pensize(1)
    turtle.pencolor("gray")
    turtle.penup()
    turtle.goto(-290, 0)
    turtle.pendown()
    turtle.goto(290, 0)
    turtle.penup()
    turtle.goto(0, -200)
    turtle.pendown()
    turtle.goto(0, 200)

    # a) Linienzug
    turtle.pensize(3)
    turtle.pencolor("darkslateblue")
    turtle.penup()
    turtle.goto(x_werte[0], y_werte[0])
    turtle.pendown()
    for i in range(1, anzahl):
        turtle.goto(x_werte[i], y_werte[i])

    # b) + c) Marker und Beschriftung
    turtle.penup()
    for i in range(anzahl):
        turtle.goto(x_werte[i], y_werte[i])

Zwei parallele Listen speichern eine Beziehung über den gemeinsamen Index: Der Punkt Nummer i hat die Koordinaten (x_werte[i], y_werte[i]).

2 Unterrichtsstunden  ·  Anwendung aller Bausteine - Anregung des Rahmenplans, ohne Laufzeituntersuchungen.

  • einen vorgegebenen Algorithmus auf einer linearen Liste implementieren

Das brauchst du

In diesem Kapitel kommt nichts grundsätzlich Neues hinzu. Alles, was du brauchst, hast du schon: Sequenz, Verzweigung, Wiederholung, Funktionen und Listen.

Neu ist nur die Arbeitsweise: Ein Algorithmus wird vorgegeben, und du setzt ihn um — statt dir selbst einen auszudenken.

Lineare Suche (gegebener Algorithmus)
i ← 0, gefunden ← falsch
solange i < Anzahl und nicht gefunden
liste[i] == gesucht janein
gefunden ← wahr
i ← i + 1

Minimum-Sortieren (Selectionsort) in Worten: Suche das kleinste Element im noch unsortierten Rest, tausche es an den Anfang dieses Restbereichs, rücke die Grenze um eins weiter. Wiederhole, bis der Rest nur noch ein Element hat.

liste[a], liste[b] = liste[b], liste[a]    # Tausch in einer Zeile

Laufzeituntersuchungen sind hier nicht Gegenstand. Es geht um das Verstehen und Implementieren eines vorgegebenen Ablaufs, nicht um Effizienz.

8.2
Minimum-Sortieren visualisiert
Standard

Implementiere das Minimum-Sortieren und zeichne die Liste nach jedem Tausch neu.

Der Algorithmus ist vorgegeben:

  1. Für jede Stelle k von 0 bis Anzahl − 2:
  2. Suche im Bereich ab k die Stelle des kleinsten Elements.
  3. Tausche dieses Element mit dem an der Stelle k.

Färbe den bereits sortierten Anfangsbereich grün, den gerade betrachteten Bereich blau und das aktuelle Minimum orange.

Tipp 1Für Schritt 2 kannst du deine Funktion aus Aufgabe 7.6 anpassen: kleinste_stelle(liste, ab) mit einem zusätzlichen Startparameter.
Tipp 2Tauschen geht in Python in einer Zeile: liste[k], liste[m] = liste[m], liste[k].
Tipp 3Schreibe eine Funktion zeichne(liste, k, m), die alles neu malt und dabei die Farben nach k und m auswählt.
Tipp 4Die äußere Schleife läuft bis len(liste) - 1: Wenn alle bis auf das letzte Element sortiert sind, ist auch das letzte am richtigen Platz.
Lösung und Erläuterung
import turtle
import time
import random

BREITE = 34
LUECKE = 5
BASIS_Y = -150

werte = []
for i in range(12):
    werte.append(random.randint(30, 200))

START_X = -(len(werte) * (BREITE + LUECKE)) / 2


def zeichne(liste, k, m):
    """Zeichnet das Diagramm. k = Grenze des sortierten Bereichs, m = aktuelles Minimum."""
    turtle.clear()

    for s in range(len(liste)):
        if s < k:
            farbe = "seagreen"          # schon sortiert
        elif s == m:
            farbe = "darkorange"        # aktuelles Minimum
        else:
            farbe = "steelblue"         # noch unsortiert

        x = START_X + s * (BREITE + LUECKE)
        turtle.penup()
        turtle.goto(x, BASIS_Y)
        turtle.setheading(0)
        turtle.pendown()
        turtle.fillcolor(farbe)
        turtle.begin_fill()
        for i in range(2):
            turtle.forward(BREITE)
            turtle.left(90)
            turtle.forward(liste[s])
            turtle.left(90)
        turtle.end_fill()

        turtle.penup()
        turtle.goto(x + BREITE / 2, BASIS_Y + liste[s] + 6)
        turtle.write(str(liste[s]), align="center", font=("Arial", 9, "normal"))

    turtle.goto(0, 205)
    turtle.write("Minimum-Sortieren   -   sortiert bis Stelle " + str(k),
                 align="center", font=("Arial", 14, "bold"))
    turtle.update()
    time.sleep(0.6)


def kleinste_stelle(liste, ab):
    """Liefert die Stelle des kleinsten Elements ab der Stelle 'ab'."""
    beste = ab
    for i in range(ab + 1, len(liste)):
        if liste[i] < liste[beste]:
            beste = i
    return beste


turtle.speed(0)
turtle.tracer(0)
turtle.pensize(1)
turtle.hideturtle()

zeichne(werte, 0, -1)

# --- Minimum-Sortieren ---
for k in range(len(werte) - 1):
    m = kleinste_stelle(werte, k)
    zeichne(werte, k, m)                    # Minimum hervorheben

    werte[k], werte[m] = werte[m], werte[k]  # tauschen
    zeichne(werte, k + 1, -1)               # nach dem Tausch

zeichne(werte, len(werte), -1)

turtle.penup()
turtle.goto(0, 175)
turtle.write("fertig sortiert", align="center", font=("Arial", 12, "italic"))
turtle.update()
turtle.done()

Der Algorithmus besteht aus zwei ineinandergeschachtelten Durchläufen — genau wie die Rosette aus Aufgabe 3.4, nur dass hier Daten statt Striche verarbeitet werden.

Die Hilfsfunktion kleinste_stelle(liste, ab) ist eine direkte Verallgemeinerung deiner Maximum-Funktion aus 7.6: Sie sucht nicht mehr in der ganzen Liste, sondern nur noch im Restbereich ab ab.

Warum läuft die äußere Schleife nur bis len(werte) - 1? Sind die ersten n − 1 Elemente sortiert, muss das größte automatisch ganz hinten stehen. Der letzte Durchlauf wäre reine Verschwendung.

Der Tausch a, b = b, a ist eine Python-Besonderheit. In den meisten anderen Sprachen braucht man eine Hilfsvariable: h = liste[k]; liste[k] = liste[m]; liste[m] = h. Lass die Schüler beide Varianten schreiben — das schärft das Verständnis für Zuweisungen.

8.3
Bubblesort im Vergleich
Erweiterung

Implementiere zusätzlich das Bubblesort-Verfahren:

  1. Gehe die Liste von vorn bis zum vorletzten Element durch.
  2. Ist ein Element größer als sein rechter Nachbar, tausche beide.
  3. Wiederhole den Durchgang, bis in einem kompletten Durchgang kein Tausch mehr nötig war.

Zähle die Tausche mit und zeige sie an. Vergleiche das Verhalten mit dem Minimum-Sortieren aus 8.2 — beobachtend, ohne Laufzeitmessung.

Tipp 1Punkt 3 verlangt eine while-Schleife mit einer Merkvariablen: getauscht = True vor der Schleife, im Durchgang auf False setzen und bei jedem Tausch wieder auf True.
Tipp 2Der Vergleich ist if liste[i] > liste[i + 1]: — deshalb darf i nur bis len(liste) - 2 laufen.
Tipp 3Für die Animation reicht es, nach jedem Tausch neu zu zeichnen — sonst wird es sehr langsam.
Lösung und Erläuterung
import turtle
import time
import random

BREITE = 34
LUECKE = 5
BASIS_Y = -150

werte = []
for i in range(12):
    werte.append(random.randint(30, 200))

START_X = -(len(werte) * (BREITE + LUECKE)) / 2


def zeichne(liste, a, b, tausche, durchgang):
    """a und b sind die gerade verglichenen Stellen."""
    turtle.clear()

    for s in range(len(liste)):
        if s == a or s == b:
            farbe = "darkorange"
        else:
            farbe = "steelblue"

        x = START_X + s * (BREITE + LUECKE)
        turtle.penup()
        turtle.goto(x, BASIS_Y)
        turtle.setheading(0)
        turtle.pendown()
        turtle.fillcolor(farbe)
        turtle.begin_fill()
        for i in range(2):
            turtle.forward(BREITE)
            turtle.left(90)
            turtle.forward(liste[s])
            turtle.left(90)
        turtle.end_fill()

    turtle.penup()
    turtle.goto(0, 205)
    turtle.write("Bubblesort   -   Durchgang " + str(durchgang)
                 + ",  Tausche: " + str(tausche),
                 align="center", font=("Arial", 14, "bold"))
    turtle.update()
    time.sleep(0.25)


turtle.speed(0)
turtle.tracer(0)
turtle.pensize(1)
turtle.hideturtle()

tausche = 0
durchgang = 0
getauscht = True

while getauscht:
    getauscht = False
    durchgang = durchgang + 1

    for i in range(len(werte) - 1):
        if werte[i] > werte[i + 1]:
            werte[i], werte[i + 1] = werte[i + 1], werte[i]
            tausche = tausche + 1
            getauscht = True
            zeichne(werte, i, i + 1, tausche, durchgang)

zeichne(werte, -1, -1, tausche, durchgang)

turtle.penup()
turtle.goto(0, 175)
turtle.write("fertig nach " + str(durchgang) + " Durchgaengen und "
             + str(tausche) + " Tauschen",
             align="center", font=("Arial", 12, "italic"))
turtle.update()
turtle.done()

Der Unterschied zum Minimum-Sortieren ist gut zu sehen:

  • Minimum-Sortieren braucht immer genau n − 1 Tausche — wenige, aber viele Vergleiche.
  • Bubblesort tauscht sehr oft; große Werte „blubbern“ sichtbar nach rechts. Bei einer fast sortierten Liste ist es dagegen nach einem Durchgang fertig.

Die Merkvariable getauscht ist das eigentlich Interessante: Sie macht die Abbruchbedingung datenabhängig statt fest. Deshalb braucht man hier while und nicht for.

Der Rahmenplan schließt Laufzeituntersuchungen ausdrücklich aus — der Vergleich bleibt also qualitativ und beobachtend. Wer mag, kann die Tauschzahlen notieren; eine O-Notation ist hier nicht das Ziel.

import turtle

# BEISPIELLOESUNG: Notenspiegel
# Erfuellt alle Kriterien und dient als Orientierung, nicht als Vorlage
# zum Abschreiben.
# ---------------------------------------------------------------

noten = [1, 2, 2, 3, 1, 4, 2, 3, 5, 2, 1, 3, 4, 2, 6, 3, 2, 1]

FARBEN = ["seagreen", "yellowgreen", "gold", "orange", "orangered", "crimson"]
BREITE = 60
BASIS_Y = -150


def zaehle(liste, note):
    """Liefert zurueck, wie oft eine Note vorkommt (Funktion MIT Rueckgabewert)."""
    anzahl = 0
    for wert in liste:
        if wert == note:
            anzahl = anzahl + 1
    return anzahl


def durchschnitt(liste):
    """Liefert den Notendurchschnitt (Funktion MIT Rueckgabewert)."""
    summe = 0
    for wert in liste:
        summe = summe + wert
    return summe / len(liste)


def saeule(x, hoehe, farbe, beschriftung):

    turtle.fillcolor(farbe)
    turtle.begin_fill()

        turtle.left(90)
        turtle.forward(hoehe)
        turtle.left(90)
    turtle.end_fill()

    turtle.goto(x + BREITE / 2, BASIS_Y - 30)
    turtle.write(beschriftung, align="center", font=("Arial", 12, "bold"))
